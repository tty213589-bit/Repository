# Cambodia Product Studio

A $0-paid-API, mobile-first PWA for Cambodia resellers.

## Main flow
- Paste a Taobao/Tmall link.
- The app attempts public-only extraction through Jina Reader basic access.
- If Taobao blocks access, continue in the manual editor and upload screenshots/product images.
- Edit price, shipping, local market price and target margin.
- Generate Khmer + English sales copy and a 4:5 PNG poster.
- Save products locally and export/import JSON backups.

## Privacy
The app never requests Taobao passwords, OTPs, bank credentials, cookies or session tokens.

## Important limitation
Taobao can block automated public reading or return incomplete data. This app does not bypass those controls. Manual import remains available.
